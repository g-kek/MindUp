# dialogum

Telegram-бот для ежедневной 10-15 минутной практики английского через голос,
диалог и персонализированную обратную связь.

## IELTS Speaking и персональная работа над ошибками

Обычная практика, `/ielts` и своя тема запускают короткую последовательность из пяти ответов:
два вопроса Part 1, карточка Part 2, два связанных вопроса Part 3. Для Part 2 бот предлагает
минуту подготовки и 1–2 минуты речи. Таймер не принудительный; это учебная практика,
а не полный пробный экзамен на 11–14 минут. План и текущий ход сохраняются в SQLite,
поэтому после перезапуска бот продолжит с нужной части.

Главный приоритет — точность речи: времена и вид, формы be/вспомогательных глаголов,
согласование и окончания, артикли, предлоги, глагольные шаблоны, порядок слов и вопросы,
условные предложения, модальные глаголы, исчисляемость и множественное число, сравнения,
относительные предложения, сочетаемость, идиомы и выбор слова. Словарь и повторение фраз
продолжают работать.

После практики бот показывает до 12 конкретных ошибок в карточках со стрелками:
исходная цитата → исправление → правило → возможная причина с наблюдениями → персональное
упражнение. Причина обозначается как гипотеза; при недостатке данных бот должен сказать об этом.
Ссылки на справочники British Council и Cambridge выбираются из каталога в коде,
а не генерируются моделью. Для идиом и выбора слова доступны общие справочники.
AI может пропустить ошибку или неверно её классифицировать; проверка цитат подтверждает
только происхождение примера, а не правильность лингвистического заключения.

`/progress` показывает повторяющиеся ошибки и удачные применения по 15 категориям.
Одно правило учитывается один раз за сессию: любая ошибка имеет приоритет над удачным примером.
После двух отдельных сессий с верным применением после ошибки появляется статус «Есть улучшение»,
после трёх — «Закрепляется». Отсутствие примера не считается успехом. Это наблюдения по категориям,
а не доказательство освоения каждого отдельного грамматического шаблона. История и конкретные
примеры передаются в подбор тем, tutor, разбор и генератор упражнений; повторяющиеся грамматические
ошибки имеют приоритет перед лексикой.

Голос расшифровывается дословно без перевода и исправления ошибок. Неуверенные фрагменты
помечаются `[unclear]`; такие сообщения исключаются из наблюдений по правилам.
Разбор IELTS опирается на текст: связность, лексика, грамматический диапазон и точность.
Произношение, темп и общий IELTS band по расшифровке не оцениваются. Оценки 1–5 — учебные,
а примерный CEFR не является результатом экзамена.

Миграция базы выполняется при старте: добавляются план IELTS и таблица наблюдений,
существующие профили, словарь и сессии сохраняются. Уже начатый разговор продолжится
в прежнем формате. Старые разборы доступны, но без автоматического переноса в новую
статистику правил. При сбое анализа сессия сохраняется без выдуманных оценок и наблюдений.

Формат и критерии сверены с [официальным описанием IELTS Speaking](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-speaking).
Грамматические справочники: [British Council](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference),
[Cambridge Grammar](https://dictionary.cambridge.org/grammar/british-grammar).

## Тренировка выбранного правила или темы

Нажми **🧩 Отработать правило** и напиши, что хочешь отработать, или сразу используй команду:

```text
/train Past Simple vs Present Perfect
/train in/on/at
/train условные предложения
/train путешествия
```

Бот учитывает уровень, историю речевых ошибок и предыдущие упражнения. Сначала даёт короткое
объяснение, 2–4 контрастных примера и ссылки на справочники. Затем — пять интерактивных заданий:
два выбора из двух вариантов, заполнение пропуска, исправление фразы и собственный ответ.
Для сравнений времён задания должны включать обе формы с контекстом, позволяющим выбрать нужную.
Для обычной темы бот выбирает полезные языковые конструкции и тренирует их в ситуациях по теме.

Выбор проверяется сразу по ключу задания. Остальные ответы проверяет AI: он принимает корректные
альтернативы, объясняет ошибки и даёт подсказку с учётом предыдущих попыток. Можно отвечать текстом
или голосом; номер варианта также выбирается кнопкой. При недоступной проверке задание остаётся
текущим, ответ можно отправить ещё раз. Ключи заданий и лингвистический разбор создаются AI.

`/train` без аргументов продолжает сохранённую тренировку после перезапуска. `/train новая тема`
начинает новую; ответы предыдущей сохраняются. `/finish` завершает тренировку досрочно.
Перед тренировкой нужно закончить активную speaking-сессию. Если начать speaking во время
тренировки, к сохранённым упражнениям можно вернуться через `/train` после завершения разговора.

Результаты последних трёх тренировок показываются в `/progress`. Они хранятся отдельно от
наблюдений по свободной речи и помогают подобрать следующий материал; не повышают CEFR,
серию speaking-практик или статус освоения правил автоматически.

## Возможности

- `/start` с онбордингом на 6 вопросов.
- Профиль пользователя: уровень, цель, темы, стиль исправлений, напоминания, язык UI.
- Короткая IELTS Speaking practice на пять ответов с Part 1–3.
- Разделенные AI-роли:
  - `TopicSelector`
  - `Tutor`
  - `Evaluator`
  - `MemoryUpdater`
- Голос пользователя: Telegram voice -> Gemini audio transcription.
- Голос бота: text -> `edge-tts` MP3 -> Telegram `send_voice`.
- SQLite-память: профиль, текущая сессия, сообщения, memory summaries, последние темы.
- Меню: practice, profile, settings, help.
- Своя тема: пользователь может написать тему и начать сессию вокруг нее.
- Перевод tutor-текста по inline-кнопке под сообщением.
- Анализ прогресса по последним сессиям и последним 24 часам.
- Словарь изученных фраз с сохранением после разбора сессии.
- Reply-меню открывается после прохождения первичной настройки.
- Topic vocabulary preview: кнопка под tutor-сообщением показывает карточки слов и типичных разговорных фраз по теме.
- Словарь открывается карточками со стрелками влево/вправо.
- Повторение словаря через короткий translate-back quiz.
- Targeted drills: после разбора бот предлагает упражнения по приоритетной ошибке со скрытыми ответами; при отсутствии ошибок — по самому слабому score.
- Если в сессии меньше двух сообщений пользователя, бот предупреждает, что анализа не будет.
- Daily streak по завершенным практикам.
- Support и отзыв/feedback формы с пересылкой в Telegram-группы.
- Разбор сессии выводится на языке интерфейса пользователя.
- Голос бота выбирается в настройках.
- Оплата и реферальная программа в MVP скрыты и не подключены.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
```

Заполни `.env`:

```bash
TELEGRAM_BOT_TOKEN=...
GEMINI_API_KEY=...
```

Если Gemini возвращает временный `503 UNAVAILABLE` из-за высокой нагрузки, бот пробует
fallback-модели из `.env`:

```bash
GEMINI_FALLBACK_MODELS=gemini-2.5-flash-lite
GEMINI_STT_FALLBACK_MODELS=gemini-2.5-flash-lite
```

Для support/feedback можно указать Telegram chat id групп:

```bash
SUPPORT_CHAT_ID=-100...
FEEDBACK_CHAT_ID=-100...
```

Если `FEEDBACK_CHAT_ID` не задан, feedback отправляется в `SUPPORT_CHAT_ID`.

Запуск:

```bash
mindup-bot
```

или:

```bash
python -m mindup_bot.main
```

Полезные команды:

```bash
/ielts       # IELTS Speaking Parts 1–3
/train       # отработать выбранное правило, сравнение или тему
/topic       # задать свою тему
/vocabulary  # открыть словарь фраз
/review      # повторить фразу из словаря
/progress    # профиль и анализ прогресса
/support     # написать в поддержку
/feedback    # отправить продуктовый отзыв
```

## Тесты

```bash
pytest
ruff check src tests
```

Автотесты используют временную SQLite и mock-ответы AI/Telegram; сетевых вызовов и отправки
сообщений реальным пользователям нет. Для ручной проверки запусти бот с тестовым Telegram-токеном,
пройди `/ielts`, закончи все пять ответов и проверь `/progress`, карточки ошибок и `/vocabulary`.
Повтори ошибку в следующей практике, затем используй правило верно в двух-трёх отдельных практиках.
`MIN_DIALOGUE_TURNS` и `MAX_DIALOGUE_TURNS` применяются к старым разговорным сессиям;
новая последовательность IELTS всегда рассчитана на пять ответов.

## Важное про ключи

Не коммить `.env`. В репозитории должен быть только `.env.example`.
